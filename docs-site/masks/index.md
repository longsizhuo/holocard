# 卡面遮罩

卡面遮罩把一张已经做好的平面卡图拆成几张箔面遮罩，用于 [pokemon-cards-css](https://github.com/simeydotme/pokemon-cards-css) 等以遮罩控制箔面范围的渲染方式。与 HoloCard 的主功能不同，输入是带边框与文字的成品卡，而不是照片；输出是遮罩图，不做视差分层。

入口：[holocard.longsizhuo.com/masks](https://holocard.longsizhuo.com/masks)，首页页头的「卡面遮罩」。

## 使用

1. 点「选择卡图」，上传卡图。支持 JPEG、PNG、WebP、AVIF、HEIC，不超过 16 MB；长边超过 1400 像素的会先缩小。
2. 处理约需半分钟，期间页面显示「正在处理」。
3. 完成后，左侧为预览卡片，右侧勾选「哪里闪」并选择箔面类型，预览随之更新。
4. 下方列出各张遮罩，可单独下载；「下载当前组合的遮罩」下载按勾选区域合成的一张。

## 输出

每张遮罩与卡图同尺寸，为灰度加 alpha 的 PNG，两个通道取值相同：白色（不透明）表示该区域。CSS 的 `mask-image` 默认按 alpha 使用，按亮度使用（`mask-mode: luminance`）结果相同。

| 遮罩 | 内容 |
|---|---|
| 边框与文字 | 画框以外的卡面，加上检测到的文字（含画框内的文字） |
| 主角 | 画框内的主体；没有画框的全图卡在整张卡上抠 |
| 特效 | 紧贴主角、明亮且饱和的区域（火焰、光弹等），以及主角轮廓内侧一圈 |
| 文字 | 检测到的文字，单独一张，便于在组合中扣除 |

页面预览中的「背景」指画框内除主角、特效以外的部分，没有对应的单独文件。

## 组合方式

实体卡不同稀有度的箔面，大致对应这几张遮罩的不同组合。以宝可梦卡为例，与官方遮罩对照得出：

| 稀有度 | 箔面范围 |
|---|---|
| 普通闪卡（Rare Holo） | 背景（画框 − 主角 − 特效） |
| 反闪（Reverse Holo） | 边框与文字（画框以外，说明文字区也有箔面） |
| V / VMAX / VSTAR | 除主角、特效、文字以外的全部；部分卡主角也有箔面，按卡面设计选择 |
| 秘密稀有（Secret Rare） | 除主角、文字以外的全部 |
| 光辉（Radiant） | 画框以外，加上主角 |

同一稀有度的不同卡面也可能不同，组合以卡面设计为准。

## 识别方式与局限

- **画框**：不依赖模型。先找贯穿大半个卡宽的长直边，组成候选矩形，再按「边的完整程度」和「框内是否像插画」选出画框。前提是画框位于卡面上半部分，宝可梦、万智牌、游戏王均满足；找不到画框时视为全图卡，「边框与文字」只含文字。
- **主角**：BiRefNet_lite 抠图。画面中物体很多的全图卡，可能把大部分画面当作主体。
- **特效**：按规则判断，不依赖模型。背景本身明亮且饱和（如整片火焰）时，会多收或少收。
- **文字**：PaddleOCR 的 PP-OCRv4 文字检测模型，只识别位置，不识别内容。

在公开卡图上的评测结果见[本地开发](/develop/)中的 `cardmask-eval`。

## 隐私与保留

上传的卡图与生成的遮罩不进数据库，不公开，地址为随机生成，24 小时后删除。处理在 HoloCard 的服务器上完成，不发送给第三方。
