# 线稿提取

线稿提取把一张插画转成线稿：白底上的线条变成透明底，可以换线条颜色、只保留主体，下载为 PNG。

入口：[holocard.longsizhuo.com/lineart](https://holocard.longsizhuo.com/lineart)。这是独立工具，从首页页头「工具」里的「线稿提取」进入。

## 使用

1. 点「选择图片」，上传插画。支持 JPEG、PNG、WebP、AVIF、HEIC，不超过 16 MB；长边超过 1024 像素的会先缩小。
2. 处理约需半分钟，期间页面显示「正在提取」。
3. 完成后左侧为预览，透明的地方显示为棋盘格。右侧可调整：

| 控件 | 作用 | 取值 |
|---|---|---|
| 「线条深浅」 | 中间为自动色阶的结果；向右淡线也变黑、线更粗，向左只留最明显的线 | 0～100，默认 50 |
| 「线条颜色」 | 线条的颜色 | 任意颜色，默认黑色 |
| 「只要主体」 | 只保留主体上的线，背景的线去掉；认不出主体时不显示 | 开 / 关，默认开 |

4. 点「下载 PNG」，下载当前预览的线稿：透明底，尺寸与处理后的图相同。

结果 24 小时后删除。

## 识别方式与局限

线稿由 [Anime2Sketch](https://github.com/Mukosame/Anime2Sketch)（MIT）的 improved 版生成，主体由 BiRefNet_lite 抠出（同[分层流水线](/develop/pipeline#服务端抠主体-birefnet)）。与原项目的用法相比有三处不同：

- 原项目把图压成 512 的正方形再处理，竖长或横长的图线条会变形；这里按比例缩到长边 1024，四周补边到 256 的倍数，处理后裁回。
- 模型输出的线常常偏淡，且每张图淡的程度不同。这里按图自身的亮度定色阶：最暗的 1% 为全黑，中位数（背景）为全白，再由「线条深浅」调整。
- 低于 5% 不透明度的像素视为噪点去掉，背景里的淡纹理不会变成一层薄雾。

模型针对动漫风格的插画训练，平涂、有明确线条的图效果最好。照片、厚涂、大面积暗色的图，线条会断续，暗处可能出现大块填充；这类图把「线条深浅」往左调可以减少填充。

## 接口

页面使用的接口，不需要登录，结果地址为随机 UUID：

| 请求 | 说明 |
|---|---|
| `POST /api/lineart` | 请求体为图片字节，返回 `202 { id }` |
| `GET /api/lineart/<id>` | 任务状态：`state` 为 `queued`、`done` 或 `error`；完成后另有 `width`、`height`、`subject`（有没有主体遮罩）与 `files` |
| `GET /api/lineart/<id>/image.png` | 缩小后的原图 |
| `GET /api/lineart/<id>/line.png` | 灰度线稿（白底黑线，未做色阶调整） |
| `GET /api/lineart/<id>/subject.png` | 主体遮罩（灰度，白为主体）；`subject` 为 `false` 时没有 |
