# カードマスク

カードマスクは、完成した平面のカード画像をホイル用のマスクに分解します。[pokemon-cards-css](https://github.com/simeydotme/pokemon-cards-css) のように、マスクでホイルの範囲を決めるレンダリング方式で使えます。HoloCard の主な機能とは異なり、入力は写真ではなく枠と文字のある完成したカードで、出力は視差のレイヤーではなくマスク画像です。

[holocard.longsizhuo.com/masks](https://holocard.longsizhuo.com/masks?lang=ja)、またはトップページ上部の「カードマスク」から開きます。

## 使い方

1. 「カード画像を選ぶ」をクリックしてアップロードします。JPEG、PNG、WebP、AVIF、HEIC に対応し、16 MB までです。長辺が 1400 ピクセルを超える画像は先に縮小されます。
2. 処理には 30 秒ほどかかり、その間「処理中」と表示されます。
3. 完了すると左にプレビューのカードが表示されます。右で「ホイルをかける場所」とホイルの種類を選ぶと、プレビューが更新されます。
4. 下に各マスクが並び、個別にダウンロードできます。「この組み合わせのマスクをダウンロード」では、選んだ範囲を合成した 1 枚をダウンロードします。

## 出力

各マスクはカード画像と同じサイズで、グレースケールとアルファの 2 チャンネルが同じ値の PNG です。白（不透明）がその範囲を表します。CSS の `mask-image` は既定でアルファを使いますが、輝度で使っても（`mask-mode: luminance`）結果は同じです。

| マスク | 内容 |
|---|---|
| 枠と文字 | イラスト枠の外側と、検出した文字（枠内の文字を含む） |
| キャラクター | イラスト枠内の主体。枠のないフルアートのカードではカード全体から切り抜きます |
| エフェクト | キャラクターに接する明るく鮮やかな部分（炎、光弾など）と、キャラクターの輪郭の内側の帯 |
| 文字 | 検出した文字のみ。組み合わせで差し引くために別にしています |

プレビューの「背景」は、イラスト枠のうちキャラクターとエフェクト以外の部分で、対応するファイルはありません。

## 組み合わせ方

実物のカードのレアリティごとのホイルは、これらのマスクの組み合わせにおおむね対応します。ポケモンカードの公式マスクと照らし合わせた結果は次のとおりです。

| レアリティ | ホイルの範囲 |
|---|---|
| ノーマルのキラ（Rare Holo） | 背景（枠 − キャラクター − エフェクト） |
| ミラー（Reverse Holo） | 枠と文字（枠の外側。説明文の欄にもホイルがあります） |
| V / VMAX / VSTAR | キャラクター、エフェクト、文字以外のすべて。カードによってはキャラクターにもホイルがあります |
| シークレット | キャラクターと文字以外のすべて |
| かがやく | 枠の外側とキャラクター |

同じレアリティでもカードによって異なる場合があるため、カードのデザインに合わせて選んでください。

## 検出方法と制限

- **イラスト枠**：モデルを使いません。カード幅の大部分にわたる長い直線から候補の矩形を作り、辺のそろい具合と中身がイラストらしいかで枠を選びます。枠がカードの上半分にあることを前提にしており、ポケモン、マジック、遊戯王はいずれも当てはまります。枠が見つからない場合はフルアートとして扱い、「枠と文字」には文字だけが入ります。
- **キャラクター**：BiRefNet_lite による切り抜きです。物が多いフルアートのカードでは、画面の大部分を主体とみなすことがあります。
- **エフェクト**：規則による判定で、モデルを使いません。背景そのものが明るく鮮やかな場合（一面の炎など）は、多く取りすぎたり取りこぼしたりします。
- **文字**：PaddleOCR の PP-OCRv4 文字検出モデルで、位置だけを検出し、内容は読み取りません。

## プライバシーと保存期間

アップロードしたカードと生成したマスクはデータベースに保存されず、公開もされません。アドレスはランダムで、24 時間後に削除されます。処理は HoloCard のサーバーで行い、第三者には送信しません。
