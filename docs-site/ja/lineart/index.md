# 線画抽出

線画抽出はイラストを線画に変換します。白背景の線を透明背景の線にし、線の色の変更や被写体だけを残す設定をして PNG でダウンロードできます。

入口：[holocard.longsizhuo.com/lineart](https://holocard.longsizhuo.com/lineart)。独立したツールで、トップページのヘッダーの「ツール」→「線画抽出」から開けます。

## 使い方

1. 「画像を選ぶ」をクリックしてイラストをアップロードします。JPEG、PNG、WebP、AVIF、HEIC に対応し、16 MB まで。長辺が 2048 ピクセルを超える画像は先に縮小されます（検出サービスが使えずサーバー上で処理するときは 1024）。
2. 通常は 5 秒ほどで結果が出ます。検出サービスのコールドスタート（しばらく使われなかった後の 1 枚目）は 1 分ほどかかります。検出サービスが使えないときはサーバー上で処理し、数秒で線画が先に表示され、被写体の切り抜きにはさらに 20 秒ほどかかります。その間は「被写体を切り抜き中」と表示され、「被写体だけ」は使えません。
3. 左がプレビューです（透明な部分は市松模様）。右側で調整できます。

| コントロール | 効果 | 値 |
|---|---|---|
| 「線の濃さ」 | 中央は自動レベル補正の結果。右へ動かすと淡い線も黒く太くなり、左へ動かすとはっきりした線だけが残ります | 0〜100、既定 50 |
| 「線の色」 | 線の色 | 任意の色、既定は黒 |
| 「被写体だけ」 | 人物の線だけを残し、文字・枠・背景の線を除きます。絵の中のキャラクターはすべて対象です。見つからないときは表示されません | オン / オフ、既定はオン |

4. 「PNG をダウンロード」で、プレビューどおりの線画をダウンロードします。透明背景で、処理後の画像と同じサイズです。

結果は 24 時間後に削除されます。

## 仕組みと制限

線画と被写体は、GPU のあるマシンで動く検出サービスでまとめて計算します。

- 線画：[MangaLineExtraction](https://github.com/ljsabc/MangaLineExtraction_PyTorch)（MIT）。縦横比を保ったまま長辺 2048 で処理します（小さい画像は最大 2 倍まで拡大）。
- 被写体：SAM 3 で「character」「person」を探し、すべてのキャラクターのマスクを合わせます。キャラクターシートの複数の人物・表情・三面図もすべて被写体になり、文字や枠は含みません。

検出サービスが使えないときはサーバー上で処理します（線画は [Anime2Sketch](https://github.com/Mukosame/Anime2Sketch)（MIT）の improved 版、被写体は最も目立つ 1 つだけを見つける BiRefNet_lite）。

モデルの線は淡くなりがちなので、画像自身の明るさからレベルを決め（最も暗い 1% を黒、中央値＝背景を白）、「線の濃さ」で調整します。不透明度 5% 未満の画素はノイズとして除きます。

どちらの線画モデルもアニメ調の絵で学習しており、ベタ塗りで線がはっきりした絵で最もよく機能します。厚塗り、写真、暗い面積の大きい絵では線が途切れたり、暗い部分が塗りつぶされたりします。その場合は「線の濃さ」を左へ動かしてください。
