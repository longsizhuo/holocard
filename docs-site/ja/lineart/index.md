# 線画抽出

線画抽出はイラストを線画に変換します。白背景の線を透明背景の線にし、線の色の変更や被写体だけを残す設定をして PNG でダウンロードできます。

入口：[holocard.longsizhuo.com/lineart](https://holocard.longsizhuo.com/lineart)。独立したツールで、トップページのヘッダーの「ツール」→「線画抽出」から開けます。

## 使い方

1. 「画像を選ぶ」をクリックしてイラストをアップロードします。JPEG、PNG、WebP、AVIF、HEIC に対応し、16 MB まで。長辺が 1024 ピクセルを超える画像は先に縮小されます。
2. 処理には 30 秒ほどかかります。その間は「抽出中」と表示されます。
3. 完了すると左にプレビューが表示されます（透明な部分は市松模様）。右側で調整できます。

| コントロール | 効果 | 値 |
|---|---|---|
| 「線の濃さ」 | 中央は自動レベル補正の結果。右へ動かすと淡い線も黒く太くなり、左へ動かすとはっきりした線だけが残ります | 0〜100、既定 50 |
| 「線の色」 | 線の色 | 任意の色、既定は黒 |
| 「被写体だけ」 | 被写体の線だけを残し、背景の線を除きます。被写体が見つからないときは表示されません | オン / オフ、既定はオン |

4. 「PNG をダウンロード」で、プレビューどおりの線画をダウンロードします。透明背景で、処理後の画像と同じサイズです。

結果は 24 時間後に削除されます。

## 仕組みと制限

線画は [Anime2Sketch](https://github.com/Mukosame/Anime2Sketch)（MIT）の improved 版で生成し、被写体は BiRefNet_lite で切り抜きます。元のプロジェクトの使い方との違いは 3 点です。

- 元のプロジェクトは画像を 512 の正方形に縮めるため、縦長・横長の画像では線が歪みます。ここでは縦横比を保ったまま長辺 1024 に縮め、周囲を 256 の倍数まで補って処理し、あとで切り戻します。
- モデルの線は淡くなりがちで、淡さは画像ごとに違います。画像自身の明るさからレベルを決め（最も暗い 1% を黒、中央値＝背景を白）、そのうえで「線の濃さ」で調整します。
- 不透明度 5% 未満の画素はノイズとして除き、背景の淡い模様が薄いもやになるのを防ぎます。

モデルはアニメ調のイラストで学習しており、ベタ塗りで線がはっきりした絵で最もよく機能します。写真、厚塗り、暗い面積の大きい絵では線が途切れ、暗い部分が塗りつぶされることがあります。その場合は「線の濃さ」を左へ動かすと塗りつぶしが減ります。
